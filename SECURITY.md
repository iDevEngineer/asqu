# Security

If you find a security problem in Asqu, please report it privately, not in a public issue
or discussion.

**How to report:** on this repository's **Security** tab, choose **Report a vulnerability**
([direct link](https://github.com/iDevEngineer/asqu/security/advisories/new)). Only the
maintainer can see your report. No GitHub account? Use [asqu.dev/contact](https://asqu.dev/contact).

Please include what you found, the steps to show it, and which version (`asqu --version`).

**What happens next:** you'll get a reply within 7 days. Once a fix is released, the
problem is described in a public advisory, crediting you unless you'd rather not be named.

Fixes go into the newest version only. Asqu updates itself (`asqu update`), so please check
the problem still happens on the newest version first.
